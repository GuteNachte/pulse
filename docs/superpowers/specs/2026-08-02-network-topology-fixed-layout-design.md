# Pulse 固定网络拓扑重建设计

## 目标

以已确认的 `v4` 固定布局方案为唯一布局与视觉基准，重新开发网络拓扑渲染功能。正式页面不使用 React Flow，也不读取旧拖拽坐标决定设备位置。

## 保留边界

- 保留 `assets`、`asset_interfaces`、`asset_relations` 和系统状态作为唯一真实数据源。
- 保留现有拓扑查询、关系保存、关系删除、资产检查器和关系检查器能力。
- 保留家庭网与科技网两个数据域，以及首页双拓扑入口。
- 旧自由画布组件、拖拽坐标、折点和撤销栈全部退役，不再保留第二套渲染实现。

## 渲染架构

新拓扑拆成四层：

1. 数据投影层：把真实资产、接口、关系和系统状态归一化为互联网、网络设备、有线终端、无线终端及链路。
2. 固定布局层：在 `1600 x 700` 紧凑逻辑画布上分配固定槽位，不消费历史拖拽坐标。
3. DOM 卡片层：CSS Grid 和绝对定位渲染卡片、接口节点、状态灯、标签和空闲槽位。
4. SVG 连线层：根据槽位锚点生成圆角正交路径，区分光纤、有线、Wi-Fi 和链路状态。

外层只负责等比缩放固定逻辑画布。完整拓扑允许横向滚动和缩放适配，首页概览复用同一渲染器并使用紧凑密度。

## 固定布局

- 画布逻辑尺寸固定为 `1600 x 700`，背景、卡片和连线都在同一坐标系中；纵向间距保持紧凑，但不压缩卡片内容。
- 左侧 `208px` 为整高互联网宽带接入区，不能被终端槽位占用。
- 中轴网络设备从左到右排列：主网关优先，其后交换机、AP 或其他网络设备。
- 主网关基准尺寸 `300 x 130`；交换机基准尺寸 `460 x 130`；后续设备按接口数量在协调范围内扩展。
- 有线终端在上方单排，按其连接的网络设备顺序及 LAN / 端口编号升序。
- 无线终端在下方单排，按有效 IPv4 数值升序。
- 槽位数量至少覆盖当前设备，并保留明确的空闲槽位；设备新增或离线不会挤乱其他已有排序。

## 接口与节点

- WAN、PON、光口上联统一显示在网络设备左侧。
- 连接下一级网络设备的 LAN / 端口节点显示在右侧。
- 其他 LAN / 端口节点固定显示在卡片上方，并按真实端口编号排序。
- 网口数量和名称来自真实接口，不能截断或虚构。
- 无线接口在卡片下方聚合为 `5 GHz` 与 `2.4 GHz` 两个频段节点；同一频段的终端共享一条主干，随后整齐分支。
- 终端有线节点位于卡片底部，无线节点位于卡片顶部。
- 有线节点统一使用紧凑 RJ45 网口造型，包含可辨识的金属触点和卡扣轮廓；节点中心与卡片边缘重合，保持一半在卡片内、一半在卡片外，且连接路径必须命中节点中心。
- Wi-Fi 节点使用绿色圆形无线标记，光纤节点使用琥珀色双环标记；三种介质共用一致的尺寸层级、背景和边缘对比，不使用立体拟真或装饰性动画。
- 编辑仅允许选择某个真实接口是否作为 WAN；可编辑账号点击网络设备整张卡片直接打开 WAN 设置，不显示独立编辑按钮，卡片字段和接口数量在拓扑内不直接编辑。
- 左右侧节点只保留介质造型与悬停信息，不在线路上显示端口文字；端口名称继续在卡片内部或顶部 LAN 节点显示。

## 卡片内容

- 互联网宽带卡显示名称、运营商、套餐上下行、接入方式、装机地址、公网地址和状态灯。
- 网络设备卡显示名称、类型、管理地址、接口规格、真实接口节点和状态灯。
- 终端卡显示名称、类型、IPv4、连接规格、位置和状态灯。
- 互联网与终端卡片点击打开现有资产检查器；网络设备卡片点击打开 WAN 设置，连线点击打开现有关系检查器。

## 连线和状态

- 光纤：琥珀色较粗实线。
- 有线：蓝色细实线。
- Wi-Fi：绿色虚线，共享频段主干后再分支到终端。
- 连线只使用水平、垂直和圆角转折，避免斜线与交叉穿卡。
- 中轴只用于网络设备排布，不绘制贯穿画布的装饰线；画布只显示来自真实资产关系的连接。
- 当前数据没有独立连通性检测结果时显示“未检测”；不得把资产在线状态伪装成链路检测结果。
- 预留 `reachable`、`checking`、`unreachable`、`untested` 四种链路状态和速率标签，供下一阶段真实检测数据接入。

## 响应式与可访问性

- 逻辑画布始终保持 `1600:700`，完整拓扑根据浏览器可用宽度等比缩放并铺满左右空间，窗口变化后自动重新计算；拓扑容器高度跟随缩放后的画布高度，内部不显示横向或纵向滚动条，首页概览继续只按卡片宽度保持紧凑缩放。
- 卡片、按钮和文字不得因缩放发生布局跳动；长名称使用省略并保留 `title`。
- 状态不能只靠颜色表达，卡片与图例提供文本语义。
- 图标使用项目已有 `lucide-react`；卡片按钮、网络域切换和连线命中区提供明确的可访问名称。

## 验收标准

- 正式页面结构和视觉与 `v4` 预览一致，而不是自由画布的近似排列。
- `/network/home`、`/network/technology` 和首页概览均不渲染 React Flow。
- 完整拓扑页能在家庭网与科技网之间直接切换，切换后仍使用同一固定渲染器和各自真实关系数据。
- 固定画布、宽带整高区、中轴网络设备、上下槽位、排序、空闲槽位和正交路径均有自动测试。
- 反向保存的关系仍能被归一化为正确方向和端口。
- 真实浏览器中点击卡片和连线可打开现有检查器。
