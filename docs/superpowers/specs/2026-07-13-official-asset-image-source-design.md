# 官方资产图片来源设计

## 目标

设备图片 Agent 只接受资产厂商或服务商官方域名的产品图片、媒体资源和品牌 Logo。图片下载后由 Hub 本地归档；大模型只负责判断图片与当前资产的型号、外观和颜色是否匹配，不再生成检索词、发现 URL 或生成图片 URL。

## 单一来源规则

- 实体设备只接受 `official_image_url`，或来自 `product_url`、`support_url`、`official_url` 页面及其同源资源的图片。
- 服务类资产只接受服务商官方域名页面或其同源资源中的 Logo。
- 资料补全报告可以提供官方页面地址，但设备图片 Agent 只读取已写入资产主档的官方页面字段，不读取模型直接返回的图片地址。
- 不再调用博查、Openverse、SearXNG、Google 图标服务或模型 URL 发现作为图片候选来源。

## 采集与验图

1. Hub 从资产主档的官方图片地址和官方页面提取图片链接。
2. Hub 先验证域名归属、响应内容类型、可解码性、最小尺寸、尺寸比例、重复图和明显水印 / 横幅特征，并将通过的图片本地保存。
3. 如果视觉模型已配置，Hub 将已本地归档的候选缩略图和资产身份发送给模型，只接收结构化的“可用 / 不可用、置信度、理由、颜色”结果。
4. 低于置信度阈值的候选被标记并从可选主图中排除；无视觉模型时，仍可由官方来源与确定性校验形成候选，但界面明确标识为“仅官方规则已验证”。
5. 用户仍从候选中确认唯一主图，详情页只显示该主图。

## 失败语义

没有主档官方页面或图片地址时，任务失败并明确提示先通过资料补全或手工维护官方链接；不会以第三方图片、模型编造 URL 或低质量图标代替。

## 设置与可观测性

AI 设置页移除博查 Key 与模型找图开关，只保留“官方图片来源规则”和“视觉准确性校验”配置。任务摘要记录官方页面数、提取数、规则拒绝数、模型拒绝数和本地归档数。
