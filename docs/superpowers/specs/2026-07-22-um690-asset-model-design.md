# UM690 资产参数整理设计

## 目标

把现有 UM690 资产整理成可复用的迷你主机样板，确保采集到的数据能被识别为正确的硬件或接口状态，并进入正确参数分类。分类保持清晰但不过度拆分，不新增系统与软件分类。

## 资产定位

- 资产类型：迷你主机。
- 位置：家 / 卧室。
- 状态：在用。
- 用途角色：开发调试 / Pulse Hub / 局域网代理节点。
- 网络职责：Windows 上的 Clash Verge 开机自启，长期为局域网设备提供手动配置的代理服务。
- 物理接入：通过 Intel I225-V 2.5GbE 接入绿联 CM754 交换机电口 6。

Clash Verge 不承担默认网关或透明转发职责，因此不新增物理接口、网关身份或资产接入关系。代理职责仅进入用途角色和备注。

## 参数分类与顺序

详情页保留固定的“设备档案”，参数卡按关注度使用以下顺序：

1. 处理器
2. 显卡
3. 内存
4. 存储
5. 网络
6. 主板与平台
7. 接口与扩展
8. 电源
9. 外观与尺寸

没有真实数据的分类不为凑版面生成虚假参数。系统与软件、散热与环境不属于本次 UM690 参数范围。

## 已确认参数

### 处理器

- 厂商：AMD。
- 型号：Ryzen 9 6900HX with Radeon Graphics。
- 核心 / 线程：8 核 / 16 线程。

### 显卡

- 类型：处理器集成显卡。
- 型号：AMD Radeon 680M。

GameViewer、MuMu 和 Microsoft Remote Display 等虚拟显示适配器不进入实体显卡参数。

### 内存

- 总容量：32 GB。
- 模组：Hynix HMCG78AGBSA095N，16 GB x 2。
- 类型：DDR5。
- 模组标称频率：5600 MHz。
- 当前配置频率：4800 MHz。
- 通道：双通道，两个插槽均已占用。

### 存储

- 当前硬盘：Great Wall GW3300 1TB。
- 介质 / 总线：NVMe SSD。
- 当前数量：1 块。
- 2.5 英寸 SATA 位置：未安装硬盘。
- 当前健康状态由监控数据展示，不写成长期静态参数。

厂家支持的存储扩展位置与当前实际安装情况分开记录。

### 网络

- 有线网卡：Intel Ethernet Controller I225-V。
- 有线速率：2.5 Gbps。
- 有线 MAC：58:47:CA:70:6A:C2。
- 有线状态：已连接，作为主网络接口。
- IPv4：192.168.1.10。
- 无线网卡：MediaTek RZ608 Wi-Fi 6E 80MHz。
- 无线 MAC：10:6F:D9:AF:68:A7。
- Wi-Fi 状态：已启用，未连接无线网络。
- 蓝牙：RZ608 Bluetooth Adapter，已启用，当前无连接设备。

设备管理 IPv6 不进入资产档案；动态 IPv6 只作为运行态采集数据处理。

### 主板与平台

- 主板厂商：Shenzhen Meigao Electronic Equipment Co., Ltd。
- 主板型号：F7BFC。
- 主板版本：Version 1.0。
- BIOS 厂商：American Megatrends International, LLC.。
- BIOS 版本：1.20。
- BIOS 日期：2024-03-06。

主板和 BIOS 返回的 `Default string` 不作为有效序列号写入资产。

### 接口与扩展

- 显示输出、USB、音频和官方存储扩展槽按厂家能力记录。
- 网络接口的当前连接状态只在“网络”分类和接口主数据中维护，不在本卡重复。
- 未实际连接的外设和虚拟设备不生成资产关系。

### 电源

- 当前使用原装电源适配器。
- 已知输入规格：DC 19V。
- 功率或电流没有可靠来源前留空，不按同型号常见配置猜测。

### 外观与尺寸

- 机身形态：迷你主机。
- 尺寸：128 x 126.6 x 46.5 mm。
- 净重：0.6 kg。

位置只保留“家 / 卧室”，不记录桌面、柜面、平放或竖放等无维护价值的细节。

## 数据来源与优先级

1. Agent / 当前 Windows 真实采集：当前安装的处理器、显卡、内存、硬盘、主板、BIOS、网卡及接口状态。
2. 厂家资料：设备尺寸、重量、支持的接口和扩展能力。
3. 人工确认：位置、用途角色、原装电源、代理职责及无法自动判断的当前状态。

当前安装情况不得被厂家可选配置覆盖。Agent 采集不到或厂家资料不能可靠确认的字段保持空白，不使用常见配置补齐。

## 展示与编辑规则

- 设备档案继续固定展示资产编号、厂商、型号、位置、IPv4、用途角色等主档信息。
- 参数卡按本设计的关注度顺序展示，每张卡只承载一个大硬件或一个明确能力分类。
- 当前值与支持能力使用明确文案区分，例如“当前硬盘”和“官方扩展槽”。
- Wi-Fi 和蓝牙使用“已启用 / 未连接”表达当前状态，不伪装为已接入关系。
- Clash Verge 的开机自启和长期代理职责写入备注，不新增系统与软件卡。
- 备注输入继续使用所有资产编辑页的通用备注框。

## 完整度规则

迷你主机的核心完整度继续检查厂商、型号、厂家资料页、IPv4、CPU、内存、主板、存储和网卡。以下情况不应扣分：

- 电源功率没有可靠来源但已确认使用原装电源。
- Wi-Fi 已启用但未连接。
- 蓝牙当前没有连接设备。
- 2.5 英寸 SATA 位置未安装硬盘。
- 不存在有效设备序列号。

## 验证范围

- 单元测试：参数分类顺序、虚拟显示设备过滤、内存模组映射、存储当前值与扩展能力分离、Wi-Fi / 蓝牙状态文案、完整度规则。
- 数据验证：UM690 资产、主接口和交换机电口 6 关系保持一致，不新增代理关系。
- 页面验证：桌面与手机详情页参数顺序正确、卡片紧凑、无重复字段、无横向溢出。
- 回归验证：交换机、光猫、宽带及其他资产类型的参数分类和网络关系不受影响。

## 非目标

- 不新增系统与软件参数分类。
- 不把 Clash Verge 建模为独立硬件资产。
- 不把 UM690 标记为主路由、主网关或透明代理网关。
- 不记录具体摆放方向。
- 不删除现有 Agent 监控、网络接口或资产关系数据。
