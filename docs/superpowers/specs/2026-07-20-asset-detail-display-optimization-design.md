# 资产详情展示页布局优化设计

日期：2026-07-20
归属模块：`asset-center`（资产中心）

## 目标

在不改变资产数据、严格类型模板、编辑工作台和现有操作入口的前提下，提高资产详情页的首屏信息密度、长参数浏览效率和整体视觉平衡。优化继续沿用 Pulse 现有深色设计语言、卡片层级、圆角、边框、字体和图标体系，不引入新的视觉主题。

## 当前问题

以交换机详情页的真实桌面状态为视觉基准，当前页面存在四个稳定问题：

- 桌面端右侧硬件档案拥有独立滚动条，同时页面本身也可滚动，形成嵌套滚动，长参数浏览不连贯。
- 左侧设备档案宽度偏紧，资产编号、型号和管理地址容易被截断；没有设备图片时，档案卡下方出现大片没有用途的空白。
- 右侧参数组数量增加后缺少快速定位入口，用户只能持续滚动寻找目标分组。
- 参数卡本身的视觉语言一致，但长分组固定占满整行，短分组与长分组的排布不够平衡，首屏可见信息偏少。

## 方案选择

采用“单页自然滚动 + 左侧吸顶档案与参数目录 + 右侧响应式参数卡”。

- 不采用标签页：标签页会隐藏参数，查看完整设备需要反复切换，不适合资产核对场景。
- 不采用极简技术表格：虽然密度高，但会削弱当前 Pulse 的视觉层级和可读性。
- 不保留右侧独立滚动：资产参数属于同一详情页，应由页面统一承担滚动，避免滚轮焦点和滚动位置混乱。

## 页面结构

### 桌面端

- 页面保持左右双栏，左侧使用稳定的最小宽度，右侧占据主要内容空间。
- 左侧整体在进入桌面断点后吸顶，依次显示设备图片框、设备 / 线路档案和参数目录；没有封面时仍保留固定 16:9 中性空框。
- 参数目录只读取现有 `AssetParameterGroup`，显示分组标题与简短摘要，不创建新的业务数据。
- 点击目录项使用页面内锚点滚动到对应参数组；目标卡保留足够的顶部滚动偏移，避免被页面顶部遮挡。
- 当前所在参数组使用轻量边框、背景和文字反馈，不使用新的强调色。
- 右侧硬件 / 线路参数取消固定高度和内部滚动条，所有参数随页面自然滚动。

### 平板与手机端

- 回到自然单列布局，不使用左侧吸顶栏。
- 参数目录改为硬件档案标题下方的横向可滚动紧凑入口，避免占用大段纵向空间。
- 参数卡保持单列，字段和值不得横向溢出；长 URL、IPv6 和规格文本允许安全换行。

## 组件边界

### `AssetShowcaseWorkspace`

- 继续负责组合图片、档案与硬件参数，不读取新的数据源。
- 始终渲染 `AssetMediaShowcase`；没有封面时传入空数组，由展示组件渲染稳定空框。
- 向档案侧栏和硬件参数列传递同一份 `parameterGroups`，保证目录与真实分组一一对应。
- 移除制造嵌套滚动的固定高度约束，并负责桌面吸顶布局。

### `AssetParameterNavigator`

- 新增为资产中心内部展示组件，只负责渲染参数目录和当前分组反馈。
- 输入仅包含参数组 ID、标题和摘要；点击只执行页面内定位。
- 使用 `IntersectionObserver` 观察真实参数卡，更新当前分组；不写入数据库、不修改 URL 路由、不保存长期状态。
- 浏览器不支持观察能力时仍可点击目录定位，只是不显示自动跟随状态。

### `AssetHardwareSpecsColumn`

- 保留现有标题、说明、分组数量、空状态和动态公网地址操作。
- 为每个参数组提供稳定 DOM ID 和滚动偏移。
- 移除内部滚动容器；桌面端参数卡固定每排两张，所有参数卡按最高卡片统一高度，信息较少的卡片允许底部留白；长参数组不再跨两列，手机和平板保持单列自然高度。
- 在非桌面端标题下方复用紧凑参数目录。

### `AssetOverviewColumn`

- 保留身份、网络、资料和接入关系分组。
- 调整桌面侧栏的有效宽度和字段布局，优先保证编号、型号、管理地址可读。
- 仍只显示有真实值的字段；没有管理 URL 时不显示管理页面，不根据 IPv4 自动推断。

### `AssetMediaShowcase`

- 有封面时继续显示首张 16:9 主图、缩略图切换和翻页，不改变已确认的媒体逻辑。
- 没有封面时显示同尺寸、同边框和同背景的固定 16:9 空框，内容只使用现有图标和“暂无图片”中性文案。
- 空框不读取图片库、候选图或历史图片，不自动设置封面，也不提供浏览态上传入口。

## 数据与交互边界

- 不新增或迁移 PocketBase 字段、集合、接口和关系。
- 不修改严格资产类型模板、参数分组生成逻辑、资料完整度或编辑保存格式。
- 编辑、接口、关系、维护、附件和更多菜单保持原功能与位置。
- 图片、外部链接、动态公网地址刷新和自动更新开关保持完整可用。
- 页面内目录只提升浏览效率，不成为新的资产数据或路由状态。

## 可访问性与易用性

- 参数目录使用原生按钮，支持键盘聚焦和回车 / 空格触发。
- 当前分组同时通过边框、背景和字体强度表达，不只依赖颜色。
- 滚动定位尊重系统的减少动态效果设置；开启减少动态效果时使用即时定位。
- 长文本继续允许选择和复制，链接保留可识别名称、外链图标和新窗口行为。
- 桌面、平板和手机均不得出现横向页面滚动。

## 异常与空状态

- 没有硬件参数时不显示参数目录，继续展示现有中性空状态。
- 没有封面时仍显示图片空框；图片加载失败继续显示“图片读取失败”，两种状态不能混用。
- 只有一个参数组时目录可以省略，避免增加无意义的导航层。
- 参数分组在页面更新后发生增删时，目录直接跟随当前 `groups` 重建，不保留已不存在的活动项。
- 分组 ID 只使用现有稳定 ID；若 ID 缺失或重复，组件不创建猜测性业务标识，由参数分组生成逻辑负责保证契约。

## 验收标准

- 桌面端资产详情页只有页面级主滚动，不再出现硬件档案内部滚动条。
- 左侧档案在桌面端吸顶，编号、型号和管理页面在常用宽度下可读，链接仍可点击。
- 有封面时图片展示和缩略图切换保持不变；没有封面时左侧显示固定 16:9“暂无图片”空框，且不会用图库或历史图片补位。
- 两个及以上参数组时显示目录，点击每一项都能定位到正确卡片，滚动时当前分组反馈正确。
- 桌面端所有参数卡高度一致，短卡片用自然留白补齐，不增加虚假字段，也不裁切长卡片内容。
- 交换机、iFTTR 主网关、宽带线路以及无图片、无参数、长 URL、长 IPv6 等状态均保持布局稳定。
- 手机端为单列自然滚动，目录紧凑可横向浏览，页面没有横向溢出和滚动陷阱。
- 资产中心自动化测试、TypeScript 类型检查和真实浏览器桌面 / 手机验收通过，控制台无相关错误。

## 复用规则

后续所有严格类型资产继续复用同一详情展示骨架。新增资产类型只提供自己的参数组和真实字段，不自行创建另一套详情布局；只有业务流程本质不同的特殊资源，才允许在该骨架内增加经过确认的专属操作。
