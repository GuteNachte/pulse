# 网络拓扑桌面全高布局精修设计

## 目标

让 Web 桌面端完整网络拓扑真正利用浏览器可用高度。上方有线终端最多两排，中间网络设备一排，下方无线终端最多两排；即使当前设备不足五排，三段区域也要稳定占据整页结构，不再缩成画布中央的小块。

## 范围

- 只修改 `900px` 及以上的完整拓扑页 `is-fit-window` 桌面规则。
- 首页紧凑拓扑、移动端、资产主数据、排序、关系聚合、卡片点击和高亮行为保持不变。
- 不恢复 SVG 连线、自由拖拽、编辑入口、添加卡片或空设备槽位。

## 五排容量与垂直结构

- 工作区使用“上部终端区 / 中间网络设备行 / 下部终端区”三段全高网格。
- 上下终端区分别占用剩余高度，可各容纳两排终端卡；设备不足时只渲染真实卡片，终端行在各自区域内垂直居中。
- 中间网络设备行保持单排，网络行与上下终端区使用比当前更大的垂直间距，形成明确的核心层级。
- `2494 x 1194` 下使用完整尺寸；`1280 x 800` 等矮桌面自动降低卡高与间距，但仍完整显示两排终端容量和一排网络设备，不出现页面滚动条。

## 卡片尺寸

- 完整桌面终端卡使用 `210px` 到 `300px` 的自适应宽度，比当前 `180px` 到 `260px` 更大。
- 网络设备卡使用 `520px` 基准宽度并允许收缩，比当前 `440px` 更大。
- 标准桌面终端卡最小高度提升到 `146px`，网络卡高度提升到 `170px`；矮桌面分别压缩到可容纳五排的尺寸。
- 三层继续从工作区左侧展开，不把少量设备重新居中成小团块，也不把卡片无限拉伸到产生大面积内部空白。

## 节点视觉

- 完整桌面拓扑隐藏全部接口节点，包括有线端口的蓝色方框、无线频段的绿色圆圈，以及宽带和网络设备侧边节点。
- 隐藏后的节点不再参与鼠标命中、键盘焦点或点击，避免不可见交互区域遮挡卡片和关系条。
- 资产接口与关系数据继续保留，关系条中的配对编号、设备连接信息和关系悬停高亮不受影响。
- 首页紧凑拓扑和移动端节点样式本轮保持不变。

## 验收

- `2494 x 1194`：工作区三段共同利用整页高度，网络行与上下终端区间距明显增大；终端卡最大宽度约 `300px`，网络卡约 `520px`。
- `1280 x 800`：上二排、中一排、下二排的容量仍能完整容纳，无横向或纵向页面滚动、裁切和重叠。
- 完整桌面拓扑中有线端口、无线频段、宽带出口和网络设备侧边节点的可见数量均为 `0`，关系条配对编号仍保留。
- 悬停任一关系条仍同步高亮对应终端、网络设备和关联关系；移动端节点交互保持原有行为。
- lint、类型检查、拓扑专项测试、全量测试和生产构建全部通过。
