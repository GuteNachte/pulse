# 交换机网口状态详情设计

日期：2026-07-20
归属模块：`asset-center`（资产中心）

## 目标

在交换机资产详情的右侧参数区增加“网口状态”卡，逐个展示已经建档的真实端口状态，让用户无需进入编辑工作台也能看清端口是否启用、是否接线、端口角色、实际协商速率和已连接设备。

## 数据边界

- 端口名称、类型、启用状态、接线状态、支持速率、协商速率和角色只读取 `asset_interfaces`。
- 已连接设备只读取 `asset_relations` 的接口端点和关联资产；关系尚未建档时显示“对端未关联”，不根据端口名称猜测设备。
- `connection_note` 只作为人工备注补充；不复制端口状态到资产 `metadata`，不新增 PocketBase 字段或集合。
- 只对 `switch` 类型生成该参数组；其他资产类型继续沿用现有参数展示。

## 展示规则

- “网口状态”作为普通参数卡插入“硬件与端口能力”之后，继续参与桌面双列和统一高度布局。
- 端口先按物理介质排列为电口在前、光口在后，各组再按名称中的数字自然排序；这样“电口 1～8”和“10G SFP+ 光口”会稳定对应物理 1～9 号顺序。
- 每个端口占一行，左侧显示真实端口名称，右侧按“接口类型 · 启用状态 · 接线状态 · 角色 · 速率 · 对端设备 / 备注”组合展示。
- 已接线且有协商速率时优先显示协商速率；未接线时显示支持速率；数值缺失时显示“速率未确认”。
- 未接线端口明确显示“未接线”；已接线但缺少关系时明确显示“对端未关联”。
- 卡片摘要显示“已接线端口数 / 端口总数”，例如“5 / 9 已接线”。

## 异常与空状态

- 交换机没有任何接口记录时不生成“网口状态”卡，避免用模板端口数伪造接口。
- 关系中不存在当前接口端点时只影响对端设备名称，不影响接口真实启用、接线和速率状态。
- 历史关系仍存在但端口当前标记为未接线时，以接口当前状态为准，不把历史关系展示成正在连接。

## 验收标准

- 当前交换机详情显示 1～9 号真实接口，并与编辑工作台里的接口数量一致。
- 1、4、5、6、7 号已接线端口显示对应关系中的设备名称；2、3、8、9 号按当前数据显示未接线或未启用。
- 9 号光口显示真实接口类型和当前未启用 / 未接线状态，不显示 PoE 信息。
- 参数目录包含“网口状态”，点击后能定位到该卡片。
- 桌面端卡片保持双列统一高度，手机端保持单列自然高度，页面无横向溢出和控制台错误。
- 自动化测试、TypeScript 类型检查和真实浏览器验收通过。

## 复用规则

后续其他交换机无论端口数量多少，都按同一构建器读取真实接口和关系；产品模板只定义字段规则，具体端口数量、状态和连接对象始终属于单条资产数据。
