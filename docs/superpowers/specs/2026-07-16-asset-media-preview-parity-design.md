# 资产图片预览与详情展示一致性设计

## 目标

资产编辑工作台中，图片库选中后的大预览必须与资产详情页的封面展示使用完全相同的视觉规则，使预览成为最终展示的可靠参照。

## 方案

- 统一使用固定 `4:3` 画布、灰白底、圆角和细边框。
- 图片统一使用 `object-contain`，完整显示，不以裁切或拉伸填满容器。
- 图片库缩略图保持紧凑 `4:3`，仅选中后的大预览与详情封面严格对齐。
- 图片编辑和数据存储逻辑不变；此改动只统一展示容器，不更改原图、已保存的裁切版本或封面 / 图库归属。

## 实现边界

- 从资产详情展示组件抽取可复用的画布 class 或常量，由详情页封面和图片库大预览共同使用。
- 为共享样式增加测试，明确固定比例与完整显示语义。
- 浏览器验证：选中图片后，图库大预览与详情封面均为 `4:3`，并且图片边缘不被截断。

## 风险与回退

- 仅改变客户端布局，不涉及媒体记录、对象存储或 API。
- 若需回退，恢复图片库大预览自己的容器 class 即可，已保存图片不会受到影响。
