# 网络设备详情参数细分设计

## 背景

Pulse 已将物理设备详细参数统一归入固定参数目录，但路由器、网关、光猫、交换机、无线 AP 和防火墙的网络参数仍可能集中在一张“网络”卡中。网络设备的核心能力差异较大，单张卡会让光纤接入、路由管理、无线、有线和安全性能混在一起，不利于快速阅读。

本次只细化网络设备详情页的展示分类。资产主数据、严格类型模板、字段目录、编辑表单、导入导出、资料补全和完整度规则保持不变。

## 目标

- 六类网络设备使用各自稳定、可复用的详情分组。
- 同一种资产类型的所有型号遵循同一套展示规则，不写入单台设备特例。
- 继续使用现有紧凑双列参数卡；没有数据的分组不显示。
- 不暴露“网络能力 4 / 6”等内部字段目录名称。
- 保持交换机已经确认的“网络功能 / 网口状态”特殊拆分。

## 方案选择

采用按资产类型定义详情分组映射的方案。展示层根据资产类型和字段键将已有参数行分配到对应卡片，底层 14 类参数目录仍是字段归属与写入边界的唯一来源。

未采用以下方案：

- 所有网络设备共享一套固定子分类：会产生大量无关或空分类。
- 直接按字段目录的 `section` 自动拆分：内部名称不适合作为用户界面文案，历史生成编号也不稳定。

## 类型分组

### 光猫 / ONT

- 接入角色：工作角色、运营商和无线电型号核准信息。
- 光纤接入：ONU 类型、PON 标准、PON 上联能力、PON SN、光纤连接器和下联光口。
- 路由与管理：主路由、主网关、DHCP 和 LAN 网段。
- 无线网络：无线标准、2.4 GHz、5 GHz、WPS 和无线控制。
- 有线网络：LAN 总数及各速率 LAN 数量。
- 设备控制：指示灯控制、复位能力和电源开关。

管理 IPv4、管理 URL、设备产品编号、序列号、MAC 等档案字段继续进入左侧设备档案，不在右侧参数卡重复显示。

### 路由器

- 有线网络：端口数量、WAN 端口、默认端口速率。
- 无线网络：无线标准、频段、空间流、天线形态。
- 网络规划：SSID 备注、VLAN / 网段备注。

### 网关

- 接口与转发：端口数量、WAN 端口、默认端口速率。
- 网络规划：VLAN / 网段备注。

### 无线 AP

- 有线接入：端口数量、默认端口速率和 PoE 标准。
- 无线网络：无线标准、频段、空间流、天线形态、SSID 备注。
- 网络规划：VLAN / 网段备注。

供电方式继续进入统一“电源”分类，不与网络参数重复。

### 防火墙

- 接口与转发：端口数量、默认端口速率。
- 安全性能：安全吞吐、VPN 吞吐、并发会话数。
- 网络规划：VLAN / 网段备注。

### 交换机

- 网络功能：管理级别、管理入口、VLAN、端口隔离、链路聚合、交换容量等固定能力。
- 网口状态：端口能力和逐口启用、接线、角色、速率及对端关系。

交换机继续沿用现有特殊展示逻辑，不回退到通用“网络”卡。

## 展示规则

- 仅对 `router`、`gateway`、`ont`、`switch`、`ap`、`firewall` 生效。
- 管理 IPv4、MAC、管理 URL 等 `dossier` 字段继续只显示在左侧设备档案，右侧不重复。
- 只拆分存在真实数据的行；空分组不创建卡片。
- 参数行保留原有标签、值、链接、采集来源和排序。
- 分组顺序固定，不随字段返回顺序变化。
- 拆分后的卡片继续参与现有桌面双列布局和移动端单列布局，不增加内部滚动。
- 外观与尺寸、电源、平台、接口与扩展等非网络分类继续使用统一参数目录。

## 实现边界

- 在资产中心详情参数领域模块中维护网络设备展示分组规则。
- 详情页面和卡片组件继续只消费构造后的参数组，不感知类型判断细节。
- 不修改 Hub 数据结构、数据库迁移、资产保存 API 或 Agent 采集协议。
- 不新增模块；本功能继续归属必需模块 `asset-center`。

## 数据流

1. 读取资产主档和已确认 metadata。
2. 按统一参数目录生成已有参数行。
3. 网络设备的网络类参数行进入类型专属展示分组器。
4. 分组器按字段键分配、排序并删除空分组。
5. 详情页使用现有参数卡组件渲染结果。

无法识别的已注册网络字段保留在通用“网络”卡中，避免升级过程中静默丢失数据；测试会约束已知字段全部进入明确分组。

## 验证

- 增加领域测试，覆盖六类网络设备的分组标题、顺序、字段归属和空分组隐藏。
- 保留并扩展交换机“网络功能 / 网口状态”回归。
- 运行资产中心定向测试、前端类型检查和生产构建。
- 在浏览器验证当前光猫详情：原单张“网络”卡拆为对应细分卡片，参数值不丢失。
- 在浏览器复验交换机详情：网络功能和逐口状态仍正确显示，卡片布局无横向溢出。

## 非目标

- 本次不新增或删除网络设备参数。
- 本次不提前完成路由器、网关、无线 AP 或防火墙的严格字段模板评审。
- 本次不改变编辑页分区、资料完整度、列表列、拓扑关系或 Agent 采集能力。
