# 网络设备详情关注优先排序设计

## 背景

网络设备详情已经按设备类型拆成接入、转发、无线、网络规划、网络功能和网口状态等卡片，但页面仍沿用全局参数分类顺序，导致外观、电源、平台等静态规格可能排在核心网络能力之前。用户查看网络设备时，最先需要确认的是设备承担的网络角色、接入能力和端口状态。

## 目标

- 只调整网络设备详情页参数卡顺序，不改变字段内容、分组名称、卡片样式、两列布局或编辑顺序。
- 网络设备先展示类型专属网络能力，再展示平台、接口、电源、外观等静态规格。
- 顺序固定且可预测，不根据字段值或临时状态动态跳动。
- 路由器、网关、光猫 / ONT、交换机、无线 AP 和防火墙统一应用该规则；其他资产类型保持原顺序。

## 排序规则

1. 类型专属网络卡按既有定义顺序置顶。例如光猫依次为接入角色、光纤接入、路由与管理、无线网络、有线网络、设备控制；交换机依次为网络功能、网口状态。
2. 网络字段回退卡“网络”仍属于核心网络卡，排在静态规格之前。
3. 其余参数卡按主板与平台、接口与扩展、电源、外观与尺寸的顺序展示；未列出的其他硬件分类继续保持原注册表相对顺序并排在其后。
4. 空卡片继续不显示，管理 IPv4、MAC 和管理页面继续只显示在左侧设备档案。

## 实现边界

- 排序逻辑归属 `asset-center`，在参数组构造完成后执行一次稳定排序。
- 通过参数组 ID 判断类型专属网络卡，不复制每种网络设备的字段清单。
- 用纯规则测试锁定光猫、交换机和非网络设备行为，避免以后新增字段破坏顺序。

## 验收

- 光猫详情首张参数卡为“接入角色”，网络相关卡连续显示，平台与电源位于其后。
- 交换机详情先显示“网络功能”和“网口状态”，外观、电源等卡片位于其后。
- 手机、主机、NAS 等非网络设备的参数卡顺序不变。
- 资产中心测试、类型检查、生产构建和浏览器回看均通过。
