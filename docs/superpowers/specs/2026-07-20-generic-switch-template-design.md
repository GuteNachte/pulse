# 通用交换机资产模板设计

日期：2026-07-20
归属模块：`asset-center`（资产中心）

## 目标

为所有品牌、端口规模和管理能力的交换机提供同一套通用资产模板。模板只定义稳定的数据结构、固定选项和展示规则；任何具体型号、端口数量、管理地址、位置、接线状态和连接对象都只能作为用户创建资产时的数据，不能写入代码默认值、迁移或示例主数据。

## 范围与非目标

- 覆盖非网管、轻管理和全管理交换机。
- 覆盖纯电口、纯光口和电光混合设备；端口数量和端口速率由实际资产填写。
- 覆盖管理能力与当前配置状态，但不做交换机自动发现、配置下发、密码保存或实时 SNMP 采集。
- 真实端口连接通过 `asset_interfaces` 与 `asset_relations` 表达；未建档的对端只保留中性文字说明，不创建虚假资产。

## 方案选择

采用“通用交换机模板 + 动态接口清单”。

- 不采用型号专属模板：会把单台设备的端口布局误当成产品规则，无法覆盖其他交换机。
- 不采用只有一段备注的通用资产：无法准确表达上联、下联、接线状态和后续网络拓扑。
- 不把交换机与路由器、AP、ONT 共用同一网络参数集合：这些设备的 WAN、Wi-Fi、PON 等字段对交换机没有实际意义。

## 模板字段

### 基础身份

- 名称、资产编号、状态、品牌、型号、官方网站、位置、管理 IPv4、管理 IPv6、管理 URL、备注。
- 位置与管理地址遵循现有资产中心的“无 / 不适用”规则，不因未使用而扣减其他资料完整度。

### 硬件与端口能力

- 电口数量、光口数量、其他端口数量。
- 默认电口速率、默认光口速率、交换容量。
- PoE 能力为固定选择：不支持、支持但未使用、正在供电；PoE 标准和供电预算仅在支持时显示。
- 供电方式为固定选择：外置电源、内置电源、PoE 受电、其他；无法确认时显示“未确认”，不伪造规格。

### 管理与网络能力

- 管理级别固定选择：非网管、轻管理、全管理。
- 主要管理入口固定选择：无、Web、App、桌面客户端、命令行；不保存账号、密码、令牌或配置备份中的秘密字段。
- VLAN、端口隔离、链路聚合均以固定状态表示：不支持、未启用、已启用。它们不使用自由文本备注作为主要状态来源。

## 动态接口与关系

- 接口由用户按真实设备逐条创建，不因模板预设而自动生成具体端口数量。
- 每个接口固定维护：名称、接口类型（有线 / 光纤）、端口角色（上联 / 下联 / 通用）、支持速率、启用状态、物理接线状态、实际协商速率、连接说明、备注。
- 实际协商速率可明确显示“未确认”；支持速率和实际协商速率不能互相替代。
- 已建档对端通过资产关系连接到双方接口；关系必须指向真实存在的接口并保持方向可读。
- 未建档对端只显示“待建档”说明；后续建档后可补成真实关系，不能自动虚构资产或接口。

## 表单、详情、清单与兼容性

- 新增与编辑页按照“基础身份、接入信息、硬件与端口能力、管理与网络能力、接口、关系、备注”分组，固定选择项不允许自定义输入。
- 详情页优先展示管理地址、管理能力、端口容量和已确认的上下联关系；接口区按端口逐项展示连接与状态。
- 资产清单继续只显示类型、位置、管理 IPv4、接入方式和状态等可扫描信息，不把每个端口铺入列表。
- 旧交换机 metadata 允许只读兼容；新建或编辑时仅写入通用交换机白名单字段。导入、导出、资料补全、Hub 写入校验和资料完整度共用同一字段定义。

## 验收标准

- 新建不同品牌、不同端口数量与不同管理级别的交换机时，表单不会带入任何具体设备的数据。
- 非网管交换机不显示不适用的 VLAN、端口隔离和链路聚合配置输入；支持但未启用的设备明确显示“未启用”。
- 电口、光口和端口速率可按真实设备自由组合；端口连接、协商速率与资产关系不会相互伪造。
- 对端尚未建档时可保存中性连接说明，建档后能替换为真实关系。
- Hub 拒绝模板外 metadata、非法固定选项、秘密字段和不存在接口的关系；桌面与手机视口均能完成新增、编辑和查看。

## 本轮真实设备核对的使用方式

本轮梳理的一台轻管理电光混合交换机只用于验证上述通用模板是否足以记录真实上联、下联、闲置端口和未插模块光口。它的型号、地址、位置、端口数量及连接对象不会出现在模板默认值、测试夹具、初始化数据或公开文档示例中。
