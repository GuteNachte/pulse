# 网络拓扑骨干中轴设计

## 目标

完整 Web 桌面拓扑把两类关系分开表达：终端与接入设备继续使用卡片内关系条；宽带、网关、交换机等网络设备之间不再显示对应关系条，改为中间一条清晰、连续的骨干链路。

## 数据边界

- 终端关系只包含普通终端与网络设备之间的真实资产关系。
- 骨干链路只包含宽带与网络设备、网络设备与网络设备之间的真实资产关系。
- 骨干链路读取关系的真实介质：`fiber` 显示黄色，`wired` 显示蓝色；未知介质使用克制的中性色，不伪造链路类型。
- 链路排序沿用现有网络设备拓扑顺序，不按设备名称写死宽带、网关或交换机。
- 视觉层不创建、修改或保存资产、接口和关系记录。

## 桌面布局

- 中间网络设备仍为三列槽位，但每个卡片在列内左右各缩进，露出中轴链路。
- 中轴位于网络设备行垂直中心、卡片后方，线宽明显高于普通边框；卡片遮挡自身范围内的链路，只显示设备之间的连接段。
- 第一段从宽带区域右边缘连接到首个网络设备；后续连接段位于相邻网络设备之间。
- 空槽保持透明虚线轮廓，同样左右缩进，不生成虚假的中轴链路。
- 完整桌面隐藏的旧端口节点继续保持隐藏。

## 关系展示

- 终端卡保留现有接入关系条及悬停 / 键盘聚焦高亮。
- 网络设备卡只显示与终端相连的有线接入关系，不显示宽带上联和网络设备上下联关系条。
- 无线终端继续通过终端卡关系条表达接入设备；无线频段节点在完整桌面仍隐藏。
- 首页紧凑拓扑和移动端保持现有布局，不渲染新的骨干中轴。

## 验收

- 当前家庭网显示黄色宽带到主网关链路，以及蓝色主网关到交换机链路。
- 网络设备卡内不再出现“上联宽带”或网络设备互联关系条。
- 终端与接入设备的关系条、高亮和卡片跳转保持可用。
- 三个网络设备槽位都为窄边卡片，中轴在间隙中清晰可见。
- `2494 × 1194` 与 `1280 × 800` 无页面滚动、遮挡或控制台错误。
