# 资产列表网络列与接口管理设计

## 目标

将资产列表原有的“接入网络”拆分为“网络接入方式”和“网卡速率”，并让列表展示直接来自资产接口主数据。资产详情与编辑工作台提供对应的多网卡管理能力，避免列表和详情各自维护一套容易漂移的参数。

## 数据来源

- `asset_interfaces` 是网卡名称、类型、速率、接入状态和主接口的唯一事实来源。
- 继续使用现有 `name`、`kind`、`speed_mbps`、`connected`、`primary`、IP 和 MAC 字段，不新增重复的资产 metadata 字段。
- `connected=true` 表示该网卡当前用于接入；允许多张网卡同时接入。
- `primary=true` 表示首选主接口，同一资产最多一个；主接口和接入状态分别表达，不互相替代。

## 资产列表

### 网络接入方式

- 展示全部 `connected=true` 网卡的类型，去重后组合为“有线 + Wi-Fi”等短文本。
- 没有已接入网卡时显示“未接入”；接口适用但尚未建档时显示“未设置”。
- 互联网接入、网页端点等没有实体网卡语义的服务型资产使用自身接入方式；网卡列显示“无”。互联网带宽可作为接入方式下的次级信息保留，不伪装成网卡速率。

### 网卡速率

- 展示该资产的全部网卡，每张网卡一个紧凑项目，内容为网卡名称与格式化速率，例如“LAN 1 · 2.5 Gbps”。
- `connected=true` 的网卡显示绿色“接入”标识。
- `primary=true` 的网卡显示星标；如果同时接入，仍同时显示接入标识。
- 已建档但未填写速率时显示“速率未填”，不能隐藏整张网卡。
- 多张网卡允许在单元格内换行，资产行高度随内容增长，不使用横向滚动和内容裁切。

## 列表加载

- 资产列表初始化时与资产、位置、维护、系统和网站监控并行读取一次 `asset_interfaces`。
- 查询只读取列表所需字段，并在内存中按资产 ID 分组；禁止按资产逐行请求，避免 N+1 请求和列表闪烁。
- `AssetListItem` 接收当前资产的接口数组，展示逻辑收敛到独立纯函数，便于测试不同多网卡组合。

## 详情与编辑设置

- 资产详情的“接口”操作改为打开接口管理入口，而不是直接假设用户要新增接口。
- 接口管理区列出全部现有网卡，并提供新增、编辑和删除操作。
- 资产编辑工作台的“接入信息”区域复用同一份接口管理列表，可维护网卡名称、网络接入方式、速率、当前是否接入、是否主接口、IP、MAC 和备注。
- 现有接口表单继续承担单张网卡编辑，字段文案调整为用户能直接理解的“网络接入方式”“当前接入”“主接口”和“网卡速率”。
- 删除网卡需要二次确认；删除主接口或已接入网卡时，确认文案明确说明对应列表标识会消失。
- 保存、删除后刷新当前资产接口数据，列表和详情再次加载时读取同一条记录，不做 metadata 双写。

## 组件边界

- 新建可复用的接口摘要和接口管理组件，避免资产列表、详情页和编辑工作台复制格式化与状态判断。
- `asset-detail-page.tsx` 继续负责 PocketBase 保存、删除和刷新；展示组件只接收数据和回调。
- 使用项目现有 Button、Badge、Dialog、Tooltip 和 Lucide 图标，不引入新依赖。

## 错误与空态

- 接口读取失败时资产列表保留资产主数据，并显示中性的“接口读取失败”，同时保留日志与错误反馈。
- 没有接口时显示“尚未添加网卡”，并提供清晰的“添加网卡”入口。
- 只读用户能查看接口列表，但新增、编辑和删除操作禁用。

## 验收

- 资产列表表头包含“网络接入方式”和“网卡速率”两个独立列。
- 多张网卡全部显示，已接入与主接口标识准确且可同时出现。
- 有线和 Wi-Fi 同时接入时，接入方式显示“有线 + Wi-Fi”。
- 服务型资产不被错误显示为实体网卡。
- 详情接口入口和资产编辑工作台均可查看并维护现有网卡。
- 新增、编辑、删除接口后重新加载资产列表，两个网络列立即反映真实接口数据。
- 桌面和窄屏无表头错位、内容遮挡、不可读换行或横向滚动。
- 前端契约测试、类型检查、生产构建和真实浏览器交互验证通过。
