# 网络拓扑桌面卡片比例优化设计

## 目标

优化 Web 桌面端完整网络拓扑页的视觉比例。当前卡片尺寸偏小，三层设备组又集中在画布中央，超宽屏下显得松散且缺少明确的阅读起点。

## 范围

- 仅调整 `900px` 及以上桌面宽度的完整拓扑页。
- 首页紧凑拓扑、移动端、资产数据、排序、关系聚合、高亮和点击行为保持不变。
- 不恢复画布缩放、绝对坐标、SVG 连线、编辑入口或空槽位。

## 布局

- 完整拓扑工作区继续在垂直方向整体居中。
- 有线终端、网络设备和无线终端三层统一从工作区左侧开始排列，不再水平居中收拢。
- 工作区保留一致的左右内边距，使宽带信息栏和设备区之间仍有清晰边界。
- 每类设备继续按现有语义行自然换行，终端每行最多 5 台。

## 卡片尺寸

- 终端卡桌面最大宽度由 `210px` 提升到 `260px`，同一行根据可用宽度等比例收缩，避免横向溢出。
- 网络设备卡桌面基准宽度由 `360px` 提升到 `440px`，同排设备从左向右排列并允许在窄桌面下收缩。
- 卡片高度、内部信息层级、关系条和边缘节点位置不变，避免放大后形成无效空白。

## 响应式边界

- `1280px` 桌面必须容纳当前 4 台有线终端和 2 台网络设备，不出现整页横向滚动。
- 超宽屏保持卡片最大宽度，不把少量设备无限拉伸。
- 小于 `900px` 的现有移动布局本轮冻结，不新增或修改移动端规则。

## 验收

- `2494 x 1194`：设备组从左侧展开，卡片明显大于当前版本，右侧允许自然留白但不再形成中央小团块。
- `1280 x 800`：所有当前卡片完整可见，无横向溢出、裁切或相互重叠。
- 点击 `5 GHz` 仍同步高亮 2 个无线终端、1 台网络设备、1 个频段节点和 2 条关系。
- lint、类型检查、网络拓扑专项测试、全量测试和生产构建通过。
