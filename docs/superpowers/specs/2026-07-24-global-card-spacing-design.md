# 全站卡片间距收紧设计

## 目标

Pulse Web 全站卡片与卡片之间的外部间距统一收紧到 `10px`，提高信息密度和扫读效率，同时保持现有简约设计语言、内容可读性和完整交互。

## 设计边界

- 只调整承载两个及以上卡片、面板或页面区块的父级布局间距。
- 页面纵向卡片栈、多列卡片网格、详情页参数卡片区和并列工作区统一使用 `10px`。
- 不修改卡片内部 padding、标题与内容间距、表单字段间距、按钮组间距、图标与文字间距、表格单元格间距。
- 不改变卡片圆角、边框、颜色、阴影、尺寸、排序、响应式列数和任何业务交互。
- 现阶段以桌面浏览器布局为验收重点；同一父容器在窄窗口自然继承 `10px`，不单独重做移动端布局。

## 实现方案

在全局样式中新增语义变量 `--pulse-card-gap: 10px`，卡片父级布局统一改用静态可扫描的 `gap-[var(--pulse-card-gap)]`。只在确认直接子项属于卡片、面板或同级页面区块时替换原有 `gap-4` / `gap-5`，不对全仓库做机械替换。

不使用通用 `.gap-4` 覆盖，也不使用 `:has()` 自动推断卡片父级，避免影响表单和依赖 DOM 结构的隐式行为。

## 覆盖范围

- 首页、资产中心、网络拓扑、智能家居、客户端、容器、网站和告警页面。
- 系统详情中的摘要卡、图表卡、硬件卡和状态面板。
- 设置页各管理卡片、版本记录和模块面板。
- 资产详情、参数卡片和资产管理工作区。

弹窗内部表单只在存在明确的并列卡片容器时应用；普通表单布局保持原间距。

## 验证

- 增加静态契约测试，锁定全局 `10px` token 和主要页面卡片容器。
- 扫描主要页面，确认剩余 `gap-4` / `gap-5` 属于表单或卡片内部内容，而非卡片父级。
- 运行相关前端测试、类型检查和生产构建。
- 浏览器抽查首页、资产中心、系统详情、网站和设置页，确认卡片间距为 `10px`，没有重叠、溢出或可读性回退。
- 同步 `docs/release-notes-next.md` 与设置页关于版本记录。
