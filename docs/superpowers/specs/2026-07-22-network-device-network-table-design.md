# 网络设备网络详情表设计

## 目标

把网络设备详情页中分散的网络参数卡、拼接的端口说明和普通键值关系卡，统一收敛为一个紧凑的“网络详情”面板。用户应能直接比较设备能力、真实接口状态以及上下联关系，不需要逐行拆解长文本。

本功能属于 `asset-center`，继续读取资产主档、`asset_interfaces` 和 `asset_relations`。第一版不修改数据库、编辑表单、采集逻辑、资料完整度或网络拓扑。

## 适用范围

网络详情面板只用于以下物理网络设备：

- 路由器 `router`
- 网关 `gateway`
- 光猫 / ONT `ont`
- 交换机 `switch`
- 无线 AP `ap`
- 防火墙 `firewall`

宽带线路 `internet`、网页端点和非网络设备继续使用现有参数卡布局。

## 页面结构

资产详情仍保持左侧“设备图片 + 设备档案”、右侧详情的总体结构。网络设备右侧按以下顺序展示：

1. 网络详情面板
2. 其他硬件参数卡，例如主板与平台、接口与扩展、电源、外观与尺寸

网络详情面板内部按数据存在情况展示三块内容：

### 网络能力表

列为“分类、参数、当前值”。

- 分类沿用当前网络设备细分规则，例如接入角色、光纤接入、路由与管理、无线网络、有线网络、网络功能。
- 参数和值来自严格资产字段目录，不从已拼接的界面文案反向解析。
- 交换机的端口数量和支持速率作为接口能力放入此表；逐口状态只进入网口状态表。
- 指示灯、复位键、电源开关等设备控制参数不属于网络能力，继续作为普通硬件参数展示。

### 网口状态表

列为“接口、介质、启用状态、链路 / 连接、角色、速率 / 频段、对端设备”。

- 行严格来自当前资产真实的 `asset_interfaces`，不能根据产品标称端口数量生成虚假接口。
- 接口按介质和自然编号排序，有线口优先、光口随后，名称使用数字自然排序。
- “启用状态”和“链路 / 连接”分开，明确区分“未启用”“未连接”和“未记录”。
- 对端设备优先从绑定当前接口的 `connected_to` 关系读取；只有真实接口备注而无已建档对端时才显示备注或“对端未关联”。
- 连接状态优先显示真实 `connected`；频率、协商速率和标称速率按可用数据逐级回退。
- 接口数量超过 12 个时，才显示“全部、已连接、未连接、未启用”筛选；不分页，不使用内部滚动。

### 接入关系表

列为“方向、对端设备、本机接口、对端接口、链路类型、关系状态”。

- 行来自当前资产相关的 `asset_relations`。
- 网络连接根据真实接口角色和关系方向判定上联或下联，上联排在下联之前。
- 非网络关系保留既有关系类型名称。
- 缺失数据必须明确显示“方向待确认”“接口待确认”“待建档”或“对端未关联”，不伪造已确认状态。
- 宽带线路无接入关系时的“待关联接入设备”提示继续沿用原逻辑；宽带本身不进入本面板。

## 展示模型

新增纯函数展示模型 `NetworkDeviceDetailModel`：

```ts
type NetworkDeviceDetailModel = {
  capabilitySections: NetworkCapabilitySection[]
  interfaces: NetworkInterfaceRow[]
  relations: NetworkRelationRow[]
}
```

模型直接接收资产、全部资产、接口和关系数据，负责：

- 判断资产类型是否适用网络详情面板
- 从现有网络参数分组生成能力表行
- 从原始接口生成结构化接口行
- 从原始关系生成结构化关系行
- 提供稳定排序和语义状态，不包含 JSX 或视觉类名

组件只负责表格布局、状态标签、筛选和响应式展示，不重复领域判断。

## 状态语义

- 绿色：启用、已连接、正常
- 灰色：未启用、未连接、未使用
- 橙色：方向待确认、接口待确认、对端未关联、待建档
- 红色：只用于数据中明确存在的真实故障

所有状态用项目现有 `Badge` 和语义化变体呈现；不能仅依赖颜色表达，标签文字始终保留。

## 响应式

- 桌面：网络详情面板占满右侧内容宽度，三张表自然纵向排列。
- 平板：保留表头，适当合并次要信息，确保主要身份和状态仍可横向比较。
- 手机：能力表继续使用三列紧凑布局；网口和关系表改为每行上下两层的紧凑记录，不强塞七列，不造成整页横向滚动。
- 所有表均使用整页自然滚动，不创建卡片内部滚动区域。

## 空态与异常

- 某张表无数据时不显示空表；只有网络详情三类数据都为空时，才不渲染整个面板。
- 接口字段缺失时显示“未记录”，不能显示为“未启用”。
- 关系指向的资产尚未进入当前资产数据集时，显示“待建档”或“对端未关联”，保留真实关系行。
- 组件渲染不得因未知接口类型、未知链路类型或缺失展开数据而报错。

## 测试与验收

自动化测试覆盖：

- 仅网络设备生成网络详情模型
- 光猫能力分类顺序和真实无线 / PON 接口状态
- 交换机端口不再拼接成长字符串
- 上联优先于下联
- 未启用、未连接、未记录和待确认状态互不混淆
- 组件使用现有 `Table` / `Badge`，网络面板不进入普通两列参数卡
- 手机布局无强制七列表格和整页横向滚动

## 非目标

- 不新增或补录接口、关系和资产主档数据
- 不调整网络设备编辑流程
- 不修改数据库集合或 Hub API
- 不实现实时 SNMP 端口监控
- 不把宽带线路并入网络设备
- 不改网络拓扑页面
