# Asset Editor Crop Workspace Design

## 目标

将资产编辑弹窗收敛为“左侧资料维护、右侧图片工作区”：资料可以不完整保存，图片搜索在执行时给出提高检索准确度的建议；主图支持可恢复的手动裁剪，候选图可更密集地浏览和选择。

## 范围

- 左侧资料表单移除必填星号和保存前的必填阻断，字段按身份与归属、网络与类型参数、智能匹配的优先级紧凑排列。
- “获取图片”不再依赖表单必填状态。点击后根据资产类型评估当前名称、厂商、型号、服务商等资料，提示缺少哪些信息会降低检索质量；用户仍可继续或取消。
- 右侧主图区采用与详情页一致的展示比例。为当前已选主图提供“编辑图片”按钮，进入裁剪模式后可拖动、缩放、重置、取消和保存裁剪。
- 裁剪只保存显示参数，不生成第二份图片、不改变归档原图。详情页、编辑页预览和候选已选状态共同读取该参数。
- 候选图区使用更密集的响应式网格：桌面优先显示更多缩略图，移动端自动缩为较少列；候选卡只保留缩略图、来源摘要和选择状态。

## 数据模型

在当前主图对应的 frame 元数据中保存归一化裁剪值：`x`、`y`、`width`、`height`，取值范围为 `0..1`。未保存裁剪值时沿用当前完整展示逻辑。

原始图片文件和来源元数据不修改。切换主图时，新主图使用自身裁剪值；没有裁剪值则从完整图片开始。重置只删除当前主图的裁剪值。

## 交互

1. 用户在右侧点击“编辑图片”。
2. 大预览进入裁剪态：图片保持原比例，裁剪框可拖动和缩放，框外区域压暗。
3. 用户选择保存、重置或取消。保存仅更新当前主图 frame 的裁剪参数，并立即刷新右侧预览和资产详情页。
4. 点击“获取图片”时，如果图片搜索缺少推荐资料，显示明确的资料建议和继续操作；不把这些建议写成主档保存限制。

## 验收

- 横版 Logo 和设备照片都能裁剪，并在详情页与编辑页一致显示。
- 裁剪后刷新页面仍保持结果；原始归档文件 URL 不变。
- 取消和重置不会误改图片文件或其他候选图。
- 资产可在资料不完整时保存；获取图片能说明可补充的资料。
- 桌面编辑页右侧候选图同一屏显示数量增加，小屏没有横向溢出。
- 覆盖裁剪参数读取、重置、主图切换和图片搜索资料建议的单元测试，以及浏览器桌面和移动验收。
