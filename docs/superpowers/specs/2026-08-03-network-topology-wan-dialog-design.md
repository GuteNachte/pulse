# 网络拓扑 WAN 居中弹窗设计

## 目标

点击固定网络拓扑中的网络设备卡片后，将“WAN 接口”设置从右侧滑出的侧边面板改为居中弹窗。

## 范围

- 将 `TopologyWanSheet` 收口为 `TopologyWanDialog`，只修改 WAN 设置的承载容器和布局。
- 保留当前 WAN 接口选择、已连接接口禁用、保存状态、错误提示和关闭逻辑。
- 普通设备详情、连接线详情及连接编辑继续使用现有交互，不在本次调整。

## 交互与视觉

- 使用项目已有 Radix `Dialog` 封装，保持焦点锁定、Esc 关闭、遮罩和无障碍标题。
- 弹窗在桌面端居中，最大宽度 `28rem`；小窗口使用 `calc(100vw - 2rem)` 自动收窄。
- 最大高度受视口约束，内容过长时只在弹窗内部滚动。
- 标题、设备名、选择器、固定说明、错误提示和保存按钮维持当前信息顺序。

## 验收

- 源码合同确认 WAN 组件使用 `Dialog`，不再引用 `Sheet`。
- 点击华为 iFTTR 主网关卡片后，页面中央出现“WAN 接口”弹窗。
- 弹窗可关闭，保存行为不变；页面无控制台错误、遮挡或整体滚动溢出。
