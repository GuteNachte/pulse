# 首页双网络拓扑设计

## 目标

首页网络拓扑区域同时完整展示家庭网与科技网。家庭网固定在左侧，科技网固定在右侧；两块画布明显高于当前单拓扑总览，并继续保持只读、紧凑和独立。

## 采用方案

首页使用两列容器分别挂载两个现有 `TopologyWorkspace` 只读实例。每个实例独立调用 `useTopologyWorkspaceData`，分别读取 `home` 与 `technology` 数据域及其保存布局。独立页面 `/network/home` 和 `/network/technology` 保持不变，首页标题入口分别跳转到对应页面。

不把两个网络合并到同一 React Flow 画布。这样可保留现有数据域、自动布局、持久化布局和错误边界，避免一侧数据或视图适配影响另一侧。

## 界面结构

- 首页拓扑区域在桌面端使用等宽两列，左侧标题为“家庭网”，右侧标题为“科技网”。
- 每列保留紧凑统计：设备、链路、网口、无线。
- 每列保留“完整拓扑”入口，并指向对应网络页面。
- 两块只读画布统一使用 `560px` 最小高度；React Flow 在各自容器内独立执行视图适配，确保节点和线路完整可见。
- 不增加背景图、装饰层或新的交互控件，沿用现有网格、节点与线路表现。
- 当前阶段只保证桌面浏览器窗口自适应；较窄桌面窗口仍保持两列，由画布缩放完整容纳内容。

## 数据与状态

将现有首页单网络组件泛化为可配置的单域只读卡片，再由首页双拓扑容器组合两个实例。家庭网和科技网分别维护加载、错误、统计和布局状态；任一网络加载失败时只在自身卡片显示错误，不遮挡另一张拓扑。

首页不写入节点位置、连接关系或网络资料。所有编辑行为继续在独立完整拓扑页面完成。

## 验证

- 契约测试确认首页同时传入 `home` 与 `technology`，标题、入口及两列结构存在，画布最小高度为 `560px`。
- 运行网络拓扑测试、TypeScript 类型检查和前端构建。
- 在桌面浏览器验证家庭网左、科技网右、两张拓扑完整可见，无裁切、重叠、横向溢出或控制台错误。
