# 网络拓扑资产驱动布局设计

- 日期：2026-08-04
- 状态：设计已确认，待实施计划
- 范围：家庭网与科技网的只读固定拓扑展示

## 目标

网络拓扑不再承担资产新增、接口编辑、关系编辑或坐标布局保存，只作为资产中心数据的可视化投影。页面根据资产、接口和真实关系自动生成，不因不同家庭的设备数量变化而依赖手工排版。

## 已确认的视觉结构

1. 左侧固定显示互联网宽带卡片，展示运营商、套餐、接入方式、装机地址、公网地址和状态。
2. 中间网络设备保持单排，位于拓扑的纵向中轴，设备按上游到下游、从左到右排列。
3. 有线终端位于网络设备上方。靠近中轴的第一排优先填充，超过 5 台后继续向上第二排；每排从左到右最多 5 张卡片。
4. 无线终端位于网络设备下方。靠近中轴的第一排优先填充，超过 5 台后继续向下第二排；每排从左到右最多 5 张卡片。
5. 设备不足时不渲染空槽位、添加卡片或占位卡；不显示“有线终端”“网络设备”“无线终端”等分区标题。
6. 正常家庭网络按每类最多 10 台作为固定两排容量。超过 10 台时不静默丢弃数据，先允许保护性追加行，后续根据真实使用量重新评估分页或其他承载方式。
7. 宽带区域不参与终端排序，也不随设备数量移动。

## 数据边界

拓扑只读取资产中心的以下数据：

- `assets`
- `asset_interfaces`
- `asset_relations`
- 资产位置、状态和网络域元数据

不再读取或写入自由画布坐标、折点、拓扑节点位置、拓扑临时节点或独立拓扑主数据。家庭网与科技网继续按网络域读取各自真实关系，并复用同一套固定渲染规则。

## 稳定排序

- 默认排序：所有可排序设备优先按有效管理 IPv4 数值升序；缺少有效 IPv4 时才进入类型专用排序和名称 / ID 兜底。
- 网络设备：先按从互联网入口向下游的图层排序；同一层默认按管理 IPv4 升序，再以真实上联端口、接口编号、资产名称和 ID 稳定兜底。
- 有线终端：默认按管理 IPv4 升序；IP 相同或缺失时，再按上游网络设备在中轴中的顺序、实际 LAN / 电口编号、资产名称和 ID 稳定兜底。
- 无线终端：默认按有效 IPv4 数值升序；缺少有效 IPv4 时，以资产名称和 ID 稳定兜底。
- 排序结果先生成稳定序列，再按每 5 台切分为纵向行；不通过空卡片维持位置。

## 关系表达

采用“结构化关系条”，不绘制连接线。

终端卡片底部显示：

```text
接入    上游设备名称    端口 / 频段
```

示例：

```text
接入    绿联 CM754 交换机    电口 4
接入    华为 iFTTR 主网关    5 GHz
```

网络设备卡片显示其上联关系；宽带入口显示为网络设备的上游来源。关系条包含角色、上游名称、端点和轻量介质标记，文字始终是主信息，不能只依赖颜色判断。

### 关系高亮

- 每条关系条与真实关系 ID 绑定；鼠标悬停或键盘聚焦关系条时，使用同一关系 ID 同步高亮对应的网络设备接口、终端连接信息和同一关系上的其他卡片。
- 网络设备卡片上的真实端口、光口或频段入口使用相同的关系 ID；高亮时只增加描边、背景和轻微阴影，不移动、不缩放卡片，也不依赖颜色单独传达信息。
- 关系高亮不重新绘制连接线，不制造临时连线；移开鼠标或失去焦点后立即恢复默认状态。
- 多条关系共享同一接口时，悬停该接口应同时高亮所有关联卡片，并在关系条中保留“多条关系 · N”语义。
- 键盘聚焦关系条、接口入口或卡片内对应关系时，行为与鼠标悬停一致，并提供可读的 `aria-label`。

## 只读交互

- 拓扑不提供添加资产、编辑资产、编辑接口、编辑关系、拖动节点、创建连线、重连线路或保存布局入口。
- 点击设备卡片只打开资产中心只读详情；点击关系信息不进入拓扑编辑。
- 悬停或聚焦关系信息时，高亮对应网络接口和另一端关系信息；该行为只改变视觉状态，不产生数据变更。
- 资产中心资产、接口或关系发生变化后，拓扑重新读取数据并自动排列。
- 当前连通性和测速仍由后续真实检测能力提供；不得使用资产在线状态伪装链路检测状态。

## 异常与缺失数据

- 设备存在但没有真实关系：仍显示设备卡片，关系条显示“关系待确认”。
- 设备有多条关系：关系条显示“多条关系 · N”，完整内容在资产详情中查看。
- 端口、频段或上游名称缺失：显示“待确认”，不使用默认端口或虚构设备补齐。
- 资产数据加载失败：显示明确加载 / 错误状态，不渲染不完整的半套拓扑。
- 超过两排：默认不分页、不截断，保护性追加行并保留稳定排序；该情况记录为后续容量评估入口。

## 响应式要求

- 桌面完整拓扑保持每排最多 5 张卡片，画布根据可用宽度等比缩放，避免横向滚动条。
- 卡片宽度、关系条高度和网络设备中轴间距保持稳定，不因设备名称变化而改变同排卡片位置。
- 名称过长时省略显示并保留完整 `title` 或只读详情入口。
- 窄窗口继续优先保证可读性；如果固定缩放后文字不可读，应进入项目既有的窄屏降级规则，而不是把关系文字压成不可识别的一行。

## 验收标准

1. 家庭网和科技网都只使用资产中心真实资产、接口和关系生成拓扑。
2. 宽带固定左侧，网络设备单排位于纵向中轴，上下终端按中轴向外排列。
3. 有线和无线终端每排最多 5 张，设备不足不显示空槽位或添加入口。
4. 画布不显示三个分区标题，不绘制连接线，卡片关系条完整显示上游设备和端口 / 频段。
5. 悬停或键盘聚焦关系条、真实网口或频段入口时，对应关系两端同步高亮，移开后恢复；高亮不移动、不缩放、不绘制临时线。
6. 点击卡片只能进入只读详情，不出现拓扑编辑控件。
7. 无关系、多关系、缺端口和加载失败状态均有明确展示，不伪造数据。
8. 覆盖不同设备数量、两排边界、超过 10 台保护性扩展、家庭网 / 科技网切换、窗口缩放、无横向滚动条和关系高亮交互场景。
