# 网络设备网口与接入关系去重设计

## 目标

网络设备详情已经通过“网口状态”逐口展示接口、连接状态、角色、速率和对端设备。存在真实网口记录时，不再重复展示“接入关系”表及关系数量。

## 显示规则

- 网络设备存在至少一个真实接口时：显示网络能力和网口状态，不显示接入关系表、关系数量或包含“上下联关系”的副标题。
- 网络设备没有真实接口但存在关系时：保留接入关系表作为信息回退，避免关系完全不可见。
- 网络设备既没有接口也没有关系时：只按现有规则展示已确认的网络能力；全部为空时不显示网络详情面板。
- 非网络设备和宽带线路继续使用现有独立接入关系卡，不受本次调整影响。

## 数据边界

`asset_relations`、关系模型和编辑入口全部保留。网口状态继续读取关系数据以识别对端设备，网络拓扑也继续消费真实关系；本次只调整资产详情页的呈现层。

## 文案

- 有网口状态时，面板副标题为“设备能力与真实接口状态”。
- 无网口但有关系时，面板副标题为“设备能力与接入关系”。
- 顶部统计只展示当前页面实际呈现的信息。

## 验证

- 组件契约测试覆盖有接口时隐藏关系、无接口时保留关系回退。
- 模型测试继续确认关系仍参与网口对端识别。
- 浏览器验证交换机和光猫详情不再显示接入关系，网口对端设备仍正确。
- 验证宽带或普通资产的独立接入关系展示不受影响。
