# Pulse 固定网络拓扑重建实施计划

> 本计划执行已确认的 `preview/network-topology-layout.html` v4 设计。正式渲染器使用 React DOM + CSS + SVG，不再基于 React Flow。

## 1. 固定拓扑数据模型

- 新建 `fixed-canvas/fixed-topology-model.ts` 与测试。
- 从 `PulseTopologyGraph` 归一化互联网、网络设备、有线终端、无线终端及关系方向。
- 按端口编号排列有线终端，按 IPv4 数值排列无线终端。
- 聚合 `5 GHz` 与 `2.4 GHz` 无线连接。

## 2. 固定槽位与路径

- 新建 `fixed-canvas/fixed-topology-layout.ts` 与测试。
- 定义 `1600 x 700` 紧凑画布、`208px` 宽带区、中轴网络设备和上下终端槽位。
- 保留空闲槽位并生成所有接口锚点。
- 新建 `fixed-canvas/fixed-topology-paths.ts` 与测试，生成圆角正交有线、光纤和 Wi-Fi 聚合路径。

## 3. 卡片和画布组件

- 新建专用互联网、网络设备、终端卡片和 SVG 连线组件。
- 用 CSS 固定卡片尺寸、接口位置、状态灯、图例和信息密度。
- 卡片与连线点击事件适配现有 `TopologyInspectorSheet` 数据类型。
- 编辑入口只处理 WAN 接口选择，复用真实接口和关系保存能力。

## 4. 路由与首页接入

- `/network/home` 与 `/network/technology` 改用 `FixedTopologyCanvas`。
- 首页家庭网和科技网概览复用同一组件的 `overview` 密度。
- 删除路由层对旧 `TopologyWorkspace` 的调用，不再保存或读取拖拽布局用于正式显示。

## 5. 收敛旧尝试

- 撤销本轮为 React Flow 固定卡片而新增的句柄、强制坐标和样式改动。
- 保留关系检查器、关系操作和仍被其他代码引用的通用模块。
- 将旧自由画布实现隔离为未使用代码，后续再单独清理，避免扩大本次变更风险。

## 6. 版本记录与验证

- 更新 `docs/release-notes-next.md` 和设置页“关于”的 `1.0.6` Web / Hub 记录。
- 运行网络拓扑专项测试、TypeScript 类型检查和前端生产构建。
- 启动本地 `8090 + 5173` 源码环境，在真实家庭网与科技网页验证加载、卡片检查器、关系检查器和固定布局。
- 以 `v4` 预览与正式页面同尺寸截图检查画布比例、卡片位置、接口节点、连线路由、信息密度和主题一致性。

## 非本次范围

- 不发布、不推送镜像、不部署飞牛。
- 不实现真实链路测速和连通性采集，仅保留状态数据结构与视觉状态。
- 不修改资产、接口和关系的主数据结构。
