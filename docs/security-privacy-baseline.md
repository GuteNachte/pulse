# Pulse 安全与隐私基线

## 用途

这份文档记录 Pulse 当前已经核对的秘密信息和外部通信边界。它用于开发、测试和发布前复查，不代表一次检查后永久安全；相关代码、依赖或部署方式改变时需要同步更新。

## 本轮检查范围

- 当前 Git 工作树中的 Web、Hub、Agent、部署模板、脚本、测试和项目文档。
- 常见私钥、GitHub Token、云平台密钥、密码、API Key、真实 `.env` 文件和容易泄露秘密的日志或接口响应。
- Sentry、PostHog、Datadog、New Relic、OpenTelemetry 等常见使用统计、错误上报和诊断遥测。
- 代码和模板中的外部网址、通知通道、更新下载与用户配置的监控目标。

## 已确认结论

- 当前已跟踪文件没有发现常见真实私钥、平台 Token 或真实 `.env` 文件。
- 没有发现默认启用的使用统计或诊断遥测 SDK。
- 本地源码运行态核对未发现未知外联：首页、AI 设置和关于页加载的脚本、图标、清单和导航资源均来自本地；连续采样 Hub 与 Vite 进程连接时，Hub 仅连接本机和局域网客户端，Vite 仅连接本机。
- AI 与识别配置接口只向浏览器返回 API Key 是否已配置，不再返回完整 Key；设置页留空保存时保留旧 Key，输入新值时才替换。
- 本地同机 Agent 的兼容默认 Token 仅允许回环来源和回环 Host；正式部署文档要求使用项目目录外 `.env` 中的随机 Token，并限制文件权限。开发模式可以放宽至本机私网，但必须保留开发环境警告。

## 明确的业务外联

以下通信不是统计遥测，而是 Pulse 功能正常工作时可能发生的业务请求：

- 公网 IP 检测：访问 `api4.ipify.org` 或 `api6.ipify.org` 获取出口地址。
- 网站监控：访问用户主动配置的监控目标。
- 资产资料补全和图片收集：按管理员配置访问 Agnes、Bing 或资料来源网站。
- 通知：按管理员配置访问相应通知通道。
- Agent 更新：从已经认证的 Pulse Hub 获取更新包。

这些功能应遵守最少数据原则，不在请求、日志、错误提示、浏览器状态或截图中暴露密码、Token、邮箱授权码和 API Key。
