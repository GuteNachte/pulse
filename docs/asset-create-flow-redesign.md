# 添加资产流程重设计（2026-10-04 定稿，同日两次修订：资料包模型 → 整合去重模型）

本文档记录添加资产流程重设计的产品决策，作为后续实施的依据。

## 背景与定位

- 资产中心是数据基座：监控从资产来，不能反向从监控生成资产。
- "自动获取"指从**互联网**获取资产资料（规格参数 + 图片），不是从监控数据导入。
- 现有底座：Hub 已有资料补全后端（`POST /assets/{id}/enrichment-reports`），AI 按可信来源优先级（厂商官网 → 权威渠道 → 规格库）搜索网页并产出带来源链接的资料；本次把它前移到添加流程，并升级为"**多方整合去重 → 人工逐条确认**"模型。

## 两种添加模式

入口：点"添加资产"后先选模式。

### 模式一：自动获取（联网资产主路径）

1. 选分类（9 大组）→ 点相应子类型（如 网络设备 → 路由器）。
2. 输入资产名称；名称非空后"获取资产信息"按钮才可点击。
3. 点击获取 → 后台多来源搜索相关参数 → **多方整合、去重，
   合成一份"最全参数集"**（来源聚合，不给人比较多套）。
4. **参数逐条确认**：整合结果逐条列出（简单罗列，不需要特殊排版），
   人一个个点击确认哪些纳入该资产的展示（2026-10-04 二次修订）。
5. **勾选即所见**（2026-10-04 三次修订）：不需要单独预览步骤——
   勾选的参数直接按既定顺序和排版渲染显示。
6. **图片**：一次多获取一些 → 去重 → 候选图墙展示 →
   人挑选哪些加入该资产的**图片库**（一个资产多张图，不再只选一张）。
7. 不满意点"**重新获取**"再来一轮。
8. 保存时自动编号（按大类）。

### 模式二：手动创建（不联网资产 & 兜底）

- 入口在类型选择的"其他"分组（自定义类型）。
- 自定义模板：必填字段 + 可选核心字段之外，全是自定义参数——
  key-value 行编辑器，"添加一行"多一行、随时删除。
- 保存时自动编号（X-xxx）。

## 资料展示：全资产统一"参数行渲染"（2026-10-04 修订，推翻固定模板展示）

- **所有资产**（自动获取的、纯手动建的）详情页参数区统一用同一套
  参数行渲染器：分组呈现、标签列对齐、值列等宽字体、长值换行。
- 自动获取的资产：渲染内容 = 整合参数集中**被确认显示的条目**。
- 纯手动建的资产：渲染内容 = 手动维护的参数行。
- 确认显示 ≠ 定死：入库后随时可改单条、增删行（参数行编辑能力）。
- **图片库**：每个资产一个图片库（多张图，封面规则实施时定）；
  候选图去重后由人挑选入库。
- **图片编辑**（裁剪、排序、设封面等）：后续专项讨论，本轮不设计。
- 排版是硬要求：分组标题 + 两列参数网格（标签/值），整体宽度、
  字号、留白与现有设计语言一致，实现时出图给用户过目后再合入。

## 必填字段基线（定稿）

| 字段 | 规则 |
| --- | --- |
| 类型 | 必选（自动模式选子类型；手动模式即自定义） |
| 名称 | 必填，且是触发"获取资产信息"的钥匙 |
| 位置 | 全部选填 |
| 使用状态 | 不询问，默认"在用" |
| 其余参数 | 全部选填；自动模式由整合参数集中被确认的条目填充 |

## 已否决的方向（避免回头讨论）

- ~~从监控数据反向生成资产~~：违背"资产是数据基座"的定位。
- ~~网段扫描自动发现~~：新能力，与添加流程解耦，需要时单独立项。
- ~~位置必填~~：全部选填。
- ~~多套资料包挑一套~~：被"多方整合去重成一份最全参数集 + 逐条确认显示"取代（二次修订）。
- ~~确认后单独出预览~~：勾选即所见，勾选内容按既定排版直接渲染（三次修订）。
- ~~高置信度资料自动入库~~：必须逐条人工确认。
- ~~每资产单张官方图~~：改为图片库多图，去重后人工挑选入库。
- ~~按类型固定模板渲染详情~~：全资产统一参数行渲染。
